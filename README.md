# 邻里 AI · 本地生活创作工作台

面向本地生活商家的交互 demo，全部使用虚拟数据与模拟生成，不连接抖音或真实 AI 服务。

## 在线体验

[打开公开演示](https://linli-ai-studio-1101.lapiko12138.chatgpt.site/)

## 已包含的功能

- 品牌素材组：保存并切换 Logo、门店照片和展示规则。
- 商品信息：商品图、价格、核心卖点与优惠利益点。
- 热点模板：闪身步、卡点变装、反差转场，以及烘焙茶饮和探店模板。
- 模板确认：人物和环境分别选择沿用或替换，支持参考图片。
- 额外需求：自由输入补充要求，随作品写入脚本和 Prompt。
- 上传参考视频，查看可编辑的模拟反推 Prompt。
- 动态分镜预览、脚本导出、发布文案，以及导入预制成片。

## 本地打开

下载 `index.html` 后用现代浏览器打开，无需安装依赖。品牌素材和作品保存在当前浏览器；导入的视频只在当前会话预览。

三视图为形变占位，视频拆解和生成均为演示。人物与环境的替换设置会进入脚本和 Prompt，预览不代表真实 AI 合成。

## 使用 GitHub Pages

在仓库的 **Settings → Pages** 中选择：

- Source：Deploy from a branch
- Branch：main
- Folder：/ (root)

保存后，以 Pages 页面显示的 Visit site 链接为准。仓库公开与 GitHub Pages 发布是两个独立设置。
